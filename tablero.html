Falta configurar Firebase

Para que este tablero funcione en GitHub Pages, necesitas añadir tu propia configuración de Firebase en el archivo index.html.

  • Ve a la consola de Firebase y crea un proyecto gratuito.
  • Activa la autenticación Anónima.
  • Crea una base de datos Firestore.
  • Reemplaza el objeto firebaseConfig en el código fuente de este archivo con tus credenciales.
